Use hosted checkout so card data never traverses CheapSeggs. Choose neutral internal SKU codes without private preferences, and disclose that billing records can associate an individual with this merchant. Cardholder statement descriptors must be accurate, recognizable and explained before payment; no deceptive concealment. Keep marketing and private relationship data away from the processor. Confirm data retention, subprocessors, cross-border transfers, breach notice and deletion exceptions.

### Shared fulfillment requirements

Internal products/versions/offers/prices are authoritative. Checkout creates a server-priced pending intent and opaque provider reference. The browser success page never grants access. Provider adapters translate verified events into a small internal event vocabulary; no provider-specific status branching in wheel/recipe code.

Verify events using the provider’s actual supported signature/raw-body/timestamp mechanism; do not assume every adult processor implements a Stripe-style signature. If only legacy postbacks are available, require a documented authenticated server lookup or equivalent reviewed mechanism; an IP allowlist alone is insufficient. Persist unique `(processor,event_id)` plus payload digest, then atomically transition purchase/subscription and grant entitlements. Duplicate delivery returns the previous outcome; changed payload with reused ID is quarantined. Use stable transaction/line references to prevent duplicates across event types too. Retry only unapplied durable events; reconcile periodically once volume justifies a job.

Handle out-of-order refund/dispute before late payment: a terminal revoked/refunded purchase cannot be reactivated by an older paid event. Trial grants have a server end date. Cancellation ends subscription access at the paid period boundary unless refund rules require earlier revocation; payment failure has a documented limited grace or immediate stop, never an unbounded flag. Dispute suspends source grants, successful reversal can restore only the still-valid source period, and chargeback finalization revokes. Couple membership/consent checks remain independent.

The scaffold defines tables and an entitlement interface, **not** a webhook receiver, billing scheduler, reconciliation worker or tax system. `/api/payments/*` returns 503. Production commerce remains blocked pending suitability and user approval.
